# Clerking corrections — 18.220.0

The adult CPG4 calculation engine was already present, but the new-case history
formatter still labelled three vomits and frequent loose stool as warning signs.
Older manual warning choices remained visible, while several CPG4 findings were
inside a closed disclosure. This release fixes that mismatch between form,
assessment and generated note.

## Clinical sources and changes

Primary source: user-supplied `CPG Dengue4-121026 (2)-1.pdf`, *Management of
Dengue in Adults*, Fourth Edition (2026), printed pp10,14–15,28–34.
Comparison: MOH *Management of Dengue Infection in Adults*, Third Edition
(2015), Table 3, printed p15:
https://mymahtas2.moh.gov.my/files/CPG%20Dengue%20Infection%20PDF%20Final%20(1).pdf

| Finding | CPG4 handling in both adult workflows |
| --- | --- |
| No improvement / worsening as fever subsides | Visible explicit finding; includes lack of improvement, not just deterioration |
| Abdominal pain | Intense pain / tenderness is explicitly confirmed; ordinary pain alone remains a concern |
| Vomiting | More than three episodes/24 h, not three or more; this cutoff also appeared in CPG3 |
| Mental state | Lethargy, restlessness, irritability or confusion |
| Fluid accumulation | Retained |
| Postural hypotension | Visible explicit finding |
| Liver | Enlargement >2 cm, replacing the old tender-liver wording |
| Urine | Reduced / absent output for 4–6 h, explicitly confirmed |
| Bleeding | Bleeding manifestations; severe bleeding remains a separate emergency finding |
| Laboratory trend | Rising HCT with rapidly falling platelets, clinician confirmed |
| Diarrhoea | Recorded as a symptom / hydration concern; removed from adult warning classification |

Phase-aware interpretation and the existing Group A/B1/B2/C rules remain. Severe
bleeding, severe leakage with respiratory distress, organ involvement and shock
are not downgraded to ordinary warning signs. Paediatric pathways are retained.
The additional-warning override now records its clinical rationale; free text is
escaped before display. The source PDF is not republished.

## Workflow changes

- Put the adult warning review beside the symptom history, with a live summary.
  Hide the superseded adult manual list; retain it for the paediatric workflow.
- Keep pain/urine answers consistent when their corresponding CPG finding changes.
- Add optional cord TSH in mIU/L to NNJ notes and referrals. Preserve blank, zero
  and decimal values correctly; reject negative/invalid input. No new thyroid
  diagnostic threshold or treatment rule is introduced.
- Shorten dengue plans, including `Repeat FBC CM.` An explicitly chosen follow-up
  date is retained. Full calculator explanations remain available on screen;
  notes include the selected IV prescription and essential reassessment/transfer
  instructions without repeating calculator prompts.
- Restore the existing urgent-escalation sentence in NNJ notes when generated by
  the existing assessment. It had been filtered out from the final plan.
- Scope the supplemental reset handler to its own module; resetting dengue no
  longer resets the HPT import-status message or refreshes unrelated DM details.
- Clear stale referral pop-ups when assessment or clerking context changes.
- Preserve existing section IDs across quick-navigation rebuilds, so the active
  section and its navigation target stay consistent after module switches.

## Verification

- Dependency-free regression suite: normal/boundary/abnormal CPG4 findings,
  three versus four vomits, loose stool, phase, concise plans, overrides,
  existing clinical calculators and workflow contracts.
- `scripts/qa-clerking.cjs`: Chromium interaction tests for both adult dengue
  workflows, selected fluid doses, paediatric switching, editable notes/referrals,
  clipboard, reset isolation, NNJ cord TSH, urgent NNJ escalation and generation
  in DM, HPT, RME1, IUCD, ADHD and autism.
- Desktop (1365 px) and mobile (390 px) screenshots and horizontal-overflow checks.
- JavaScript syntax, whitespace, CI and deployed-asset verification before release.

These checks cover the stated scenarios; they do not establish that every
possible clinical or software error has been eliminated.
